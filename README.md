# Family Budget

Семейный бюджет в общей базе Cloudflare D1. Проект включает Telegram-бота и самостоятельное адаптивное веб-приложение.

## Веб-приложение

Веб-интерфейс отдаётся тем же Cloudflare Worker, что и бот, и использует ту же базу данных D1:

- `/` и `/app` — панель семейного бюджета;
- `/api/login` — вход по паролю;
- `/api/dashboard` — отчёт, категории, реальные остатки, платежи и история;
- `/api/expense` — запись расхода;
- `/api/income` — запись дохода;
- `/api/savings` — ручной перевод выбранной суммы в копилку;
- `/api/balance` — корректировка реального остатка основного счёта;
- `/api/payment` — запись обязательного платежа;
- `/api/stock` — отметка покупки в запас.

Веб-приложение не использует Telegram Web Apps и не требует открывать Telegram для дальнейшего доступа. После настройки пароля оно продолжает работать на Worker и с прежней базой, даже если перестать пользоваться Telegram-ботом.

### Обязательная настройка доступа

Перед использованием создай секрет **`WEB_APP_PASSWORD`** в Cloudflare:

1. Открой Cloudflare Dashboard → Workers & Pages → Worker **`familu-budget`**.
2. Открой **Settings → Variables and Secrets**.
3. Добавь секрет с именем `WEB_APP_PASSWORD`.
4. Задай отдельный сложный пароль не короче 12 символов. Не помещай пароль в этот репозиторий и не используй пароль от других сервисов.
5. Сохрани настройки и дождись перезапуска Worker.

У всех членов семьи, которым нужен доступ к веб-приложению, будет один общий пароль. Вход защищён подписанной HttpOnly cookie на 7 дней. API операций не доступно без авторизации.

### Важная финансовая логика

- Реальные деньги считаются как доходы минус расходы, минус остаток копилки, плюс отдельные ручные корректировки.
- Изменение реального остатка записывается в `balance_adjustments`. Оно не меняет историю доходов или расходов, но учитывается в текущем балансе, отчётах и расчёте свободных денег.
- Пополнение копилки проводится только на сумму, которую пользователь ввёл вручную. Оно уменьшает основной счёт и увеличивает остаток копилки, не создавая фиктивный доход или расход.
- Автоматическое распределение дохода не перечисляет сумму в копилку. Пользователь вручную решает, сколько отложить.
- Операции веб-приложения записываются в существующие таблицы. Для запуска приложения после отключения Telegram-бота не нужен Telegram Bot Token; запись в общей базе и все web API остаются доступными.
- Экран обязательных платежей показывает уже существующие записи в базе и не создаёт будущие события или платежи.
- Суммы, записанные через интерфейс, являются реальными изменениями общей базы. Пользуйся кнопками подтверждения и не повторяй действие, пока не обновишь экран после сетевой ошибки.

## Развёртывание

Проект настроен на Cloudflare Workers Python runtime с D1 binding `DB`. После обновления кода в GitHub дождись автоматического развёртывания, если репозиторий подключён к Cloudflare Builds. Если автоматическая сборка не включена, запусти существующий процесс деплоя Worker вручную.

Проверка Worker: `/health`.
